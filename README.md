# Kinakomochi Economy — Public Source

Kinakomochi Economy（mod ID: `mochieconomy`）は、Minecraft 1.12.2 用の Minecraft Forge mod です。

このリポジトリには、バージョン `0.1.0-alpha` の公開ソーススナップショットの Java ソースコードとリソースが含まれています。

## ソースコードを公開する理由

配布用 JAR ファイルは Discord を通じて共有されています。このリポジトリは、ユーザーが実装を検証し、透明性とセキュリティレビューのためにソースコードから mod をビルドできるようにするために提供されています。

**ソースコードを公開しただけでは、別途配布されている JAR ファイルがこのソースコードからビルドされたこと、またはどちらの成果物も悪意のある動作が全くないことの証明にはなりません。** より確実な検証を行うには、レビュー済みのコミットからプロジェクトをビルドし、生成された JAR ファイルを配布ファイルと比較してください。このプロジェクトは現在、JAR マニフェストにビルドタイムスタンプを埋め込んでおり、動的な ForgeGradle バージョンセレクター（`3.+`）を使用しているため、このスナップショットでは完全に再現可能なビルドは保証されません。

## ビルド

Java 8 JDKを使用し、リポジトリのルートディレクトリからGradleラッパーを実行してください。


### Windows

```bat
gradlew.bat clean build
```

### Linux / macOS

```bash
chmod +x gradlew
./gradlew clean build
```

生成されたmod JARファイルは`build/libs/`ディレクトリに生成されます。初回ビルドには、GradleおよびMinecraft Forge/Gradleの依存関係をダウンロードするためのインターネット接続が必要です。

> このソーススナップショットは公開用に整理されていますが、準備環境でのクリーンビルドの成功は独立して検証されていません。ビルドが失敗した場合は、まずJavaのバージョンと依存関係の可用性を確認してください。

## レビュー範囲

このリポジトリには、modのJavaソースコード、アセット、ローカライズファイル、Gradleビルドスクリプト、およびGradleラッパーが含まれています。開発マシンの設定、Gradleキャッシュ、生成されたビルド出力、Minecraftランタイムログ/設定、およびセーブ/ワールドデータは意図的に除外されています。


ビルドは、`build.gradle`で宣言されたリポジトリ（`maven.minecraftforge.net`とMaven Central）から依存関係をダウンロードします。サプライチェーン全体の監査が必要な場合は、サードパーティの依存関係を別途確認してください。
